# Biomechanics — Mechanism & Mathematical Modelling

Mathematical modelling and analysis of various **parallel kinematic mechanisms**, with a focus on biomechanics-related applications.

## Project Overview

This project focuses on the **mathematical modelling, kinematic analysis, optimization, and simulation** of parallel mechanisms used to model biomechanical systems.

## Installation

Clone the repository and install the required dependencies:

```bash
cd kinematics_utils
pip install -e .
```

## Parallel Kinematic Mechanisms

The project includes modelling and analysis of parallel kinematic mechanisms for:

- **Torso**
- **Ankle**
- **Knee**

The work covers areas such as:

- Kinematic modelling
- Mathematical formulation
- Forward and inverse kinematics
- Mechanism analysis
- Workspace analysis
- Optimization
- Numerical modelling and simulation
